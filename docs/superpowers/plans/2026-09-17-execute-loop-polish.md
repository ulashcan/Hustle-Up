# Execute-Loop Polish Plan

> **For agentic workers:** TDD. No StoreKit. No hosted AI. No git commit unless asked.

**Goal:** The first useful action after a MOVE is execute without fumbling — not practice, not logging an outcome you haven't lived yet.

**Architecture:** Keep models. Fix navigation uniqueness, analysis hierarchy, fumble/practice engines.

## Changes

- DID IT WORK lives on Home only (after they leave and act).
- Analysis sticky: FUMBLE CHECK primary, PRACTICE secondary, DONE ghost.
- `pushUnique` for fumble / practice / OCR / profile.
- One SAY THIS line; bracket hint; hide internal category badge.
- Empty OCR: TYPE IT INSTEAD is the primary action. No error banner on top of review.
- WAIT copy is HOLD THIS, not SAY THIS.
- SAY THIS sits directly under the MOVE.
- SEND IT exposes COPY of the original draft.
- Hedge matching uses word boundaries (`adjusting` ≠ `just`).
- Fumble: revealing leverage (`between us`, `off the record`).
- Practice: hedge/leak lines get a different opponent reply than a clean ask.
- Reduce Motion: practice auto-scroll does not animate.
